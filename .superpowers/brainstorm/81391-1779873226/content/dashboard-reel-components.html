Implementation Shape
New demo data layer
  • Curated scenario metadata in the manifest or a small helper module.
  • Scenario ids map to annotated MP4 + JSON event log.
  • Derived summaries: verdict, incident count, confidence, first event time.
  • Generated Telegram preview message from the selected scenario.
No overclaiming
  • Dashboard says “Replay Mode,” not “live deployment.”
  • Telegram panel says “Demo preview,” not “sent.”
  • Weapon detection stays out of investor reel unless a clean clip exists.
  • Generated reel avoids repeated zone incident spam.
